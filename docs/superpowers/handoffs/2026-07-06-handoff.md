## Architecture rapide

```
app/
  (admin)/admin/    → dashboard admin (villas, resas, revenus, proprio, clients, soumissions)
  (proprio)/dashboard/ → dashboard proprio (villas, resas, revenus, stats, taches)
  espace-client/    → espace voyageur (sejour, livret, favoris, messages, etc.)
  api/chat/route.ts → chatbot public (fallback FAQ offline)
  api/agent/        → contextes pour bots n8n (visitor, admin, owner, owners-digest)

lib/
  revenue/          → calculs CA, commission, ADR, occupation
  chatbot/          → FAQ, fallbacks, feedback
  emails/           → envoi emails (Resend)
  stripe/           → Stripe Connect (createAccount, onboarding, calculateTransferAmounts)

emails/             → templates React Email (12 fichiers)
components/
  chatbot/          → Chatbot.tsx (widget visiteur)
  dashboard/        → composants admin/proprio partagés
  espace-client/    → composants client
```
