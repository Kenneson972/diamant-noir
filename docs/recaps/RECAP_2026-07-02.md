## 1. Soumission acceptée → villa pré-remplie (LIVRÉ)

### Problème

À l'acceptation d'une soumission, seul le statut changeait — l'admin re-saisissait toute la villa. De plus, le formulaire public envoyait `equipements`, `surface`, `villa_type`, `photo_urls` mais le POST ne les persistait pas.

### Solution

| Couche | Fichier / action |
|--------|------------------|
| DB | 5 colonnes sur `villa_submissions` + FK `villa_id` |
| API POST | Persiste equipements/surface/type/photos |
| Lib | `mapSubmissionToVilla` (pur, testé) + `createVillaFromSubmission` (idempotent) |
| Acceptation | `updateSubmissionStatus` crée la villa brouillon si `accepted` |
| UI | Bouton « ✓ Villa créée — Ouvrir dans l'éditeur » + bandeau page détail |
| Fix | Tiers Collection éditeur alignés DB (`signature` / `iconic`) |
